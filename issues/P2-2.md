# P2-2 — `revoke()` through an expired access token silently no-ops. The access …

## Finding / 问题

- EN: `revoke()` through an expired access token silently no-ops. The access record lives only `accessTtl` (15 minutes) and its key expires, so the family is not found, while the 30-day refresh token survives. Three signed statements promised that the family could be revoked through any token of that family, and therefore did not hold. Fixed in the working tree in the confirmed documentation-only direction: the wording is tightened to "any live token of the family" in `src/TokenAuthInterface.php:35-45`, `src/TokenAuth.php:218-228` and `docs/token-auth-design/token-auth-design.html:892,904-910,916-919`, logout points at the refresh token, and behaviour is unchanged.
- 中文: 用已过期的 access token 调 `revoke()` 会静默 no-op。access 记录只活 `accessTtl`（15 分钟）、键会过期，因此找不到该族，而 30 天的 refresh token 存活。三处已署名表述都承诺「可通过该族的任意令牌撤销」，因而不成立。工作树中已按已确认的「只改文档」方向修复：措辞收紧为「该族的任意**存活**令牌」，落在 `src/TokenAuthInterface.php:35-45`、`src/TokenAuth.php:218-228` 与 `docs/token-auth-design/token-auth-design.html:892,904-910,916-919`；登出指向 refresh token；行为未变。
- Where / 位置: `src/TokenAuth.php:218-228`
