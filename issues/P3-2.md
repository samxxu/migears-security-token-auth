# P3-2 — A replay seen after the server clock moved backwards is classified as a …

## Finding / 问题

- EN: A replay seen after the server clock moved backwards is classified as a retry, keeping the family, rather than as theft. The token is still rejected, so it is fail-safe; only the anti-theft revocation is skipped. Handled in the working tree by a design-doc note at `docs/token-auth-design/token-auth-design.html:960-964`.
